# SAP screenshot evidence

Only upload **genuine screenshots from your own SAP environment**, taken after configuring or testing each part.

Suggested filenames:
- `01-build-lobby.png`: project visible in SAP Build Lobby.
- `02-employee-form.png`: configured leave request form.
- `03-workflow-canvas.png`: process and decision steps.
- `04-manager-approval.png`: human approval task.
- `05-approved-result.png`: actual approval result, when available.
- `06-rejected-result.png`: actual rejection result, when available.

For each screenshot, add a note in the README explaining what was verified.

**Privacy:** redact usernames, tenant identifiers, employee details, access tokens, emails and any other sensitive information. Never use screenshots from AAI internal systems. Screenshots must not be mocked up and presented as genuine SAP evidence.
