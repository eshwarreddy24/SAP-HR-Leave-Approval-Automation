# Resume and interview guidance

**Do not paste the completed-project bullets into a resume yet.** Use them only if the matching SAP tasks have actually been configured and tested.

## Suggested future project heading
**Employee Leave Request & Approval Automation | SAP Build Process Automation, SAP BTP**

## Bullets to use only after verified completion
- Configured an employee leave-request workflow using SAP Build Process Automation, including employee form submission, manager approval/rejection and conditional routing.
- Executed approval and rejection tests and documented observed results through workflow screenshots and test records.

If implemented and tested:
- Extended the process with HR review of approved requests and documented its handoffs and exception paths.

## Interview narrative
1. Business problem: avoid incomplete or poorly routed leave requests.
2. Scope: employee form, manager decision, optional HR review.
3. Configuration: what was actually set up in SAP Build and why.
4. Testing: approval and rejection scenarios, with observed results.
5. Limitations: what the trial couldn't support and proposed enhancements.

## Do not claim
- SAP SuccessFactors integration without configuring one.
- Classic SAP HCM ESS/MSS configuration based only on a conceptual workflow.
- Payroll automation, productivity gains or reduction in turnaround time without measurement.

Add the GitHub repository link to your resume after the completed implementation and real evidence are published.
